## 🧭 Sobre

A **Hexavante** é uma empresa de tecnologia educacional. Projetamos, construímos e operamos a nossa própria plataforma, **do banco ao deploy**, atendendo estudantes de **TI, ENEM e vestibulares**, além de instrutores e moderadores que produzem e curam o conteúdo.

O projeto é **aberto ao público e licenciado sob MIT**: você pode estudar, usar, modificar e distribuir o código.

## 🏗️ Arquitetura

```mermaid
flowchart LR
    U([👤 Usuário]) --> N{{Nginx}}

    N --> L[🌐 Landing]
    N --> W[🚀 Web]
    N --> A[🛡️ Admin]
    N --> API[⚙️ API]

    D[🖥️ Desktop] --> API
    M[📱 Mobile] --> API
    L --> API
    W --> API

    W --> DB[(🗄️ MariaDB)]
    A --> DB
    API --> DB
    API --> R[(⚡ Redis)]
```

- **Banco único.** O Web usa *migrations* versionadas e a API usa `db push`, com os dois `schema.prisma` em **paridade total** (models, campos, enums e índices). Regra dura: **nunca `--accept-data-loss`**.
- **Landing 100% via API pública.** Sem Prisma, sem sessão própria, sem importar código do app.
- **Admin é ferramenta interna** e acessa o banco direto, com atalhos "ver no app".
- **Desktop e Mobile** consomem a mesma API com o mesmo login.

## 🔐 Segurança

- **Sessão** validada na API, via cookie seguro compartilhado entre os subdomínios.
- **2FA** por código de e-mail, com verificação em dispositivos novos.
- **Multiconta**, dispositivos conectados e controle de presença.
- **Rate limit** contra brute-force.
- **Moderação auditada**: toda ação administrativa deixa rastro em log.
- **Admin isolado**, com sessão própria e verificação por código.
- **Desktop** com `contextIsolation` ativo e **Mobile** com token em secure store.

## 🚢 Engenharia

- **Deploy** em VPS com Docker + Nginx, sempre com build limpo e verificação pós-deploy (endpoints e logs).
- **Portas de qualidade** antes de dizer "pronto": `next build` no web e na landing; `tsc --noEmit` + testes do módulo alterado na API. O mesmo vale para contribuições externas.
- **Documentação como parte da entrega.** Cada sprint é tratada como produto, não só como entrega.

## 🤝 Open source e como contribuir

Todo o ecossistema é **público e licenciado sob [MIT](https://opensource.org/license/mit)**. Contribuições são bem-vindas, de correção de typo a funcionalidade nova.

| Quero… | Faça isto |
|---|---|
| 🐛 **Reportar um bug** | Abra uma *issue* no repositório correspondente, com passos para reproduzir |
| 💡 **Sugerir uma ideia** | Abra uma *issue* descrevendo o problema que a ideia resolve |
| 🔧 **Enviar código** | Faça um *fork*, crie uma branch, rode as verificações abaixo e abra um *Pull Request* |
| 📖 **Melhorar a documentação** | PRs de documentação são sempre bem-vindos |
| 🔒 **Reportar uma vulnerabilidade** | Use a aba **Security** do repositório (*private vulnerability reporting*). **Não abra issue pública** |

**Antes de abrir o PR**

```bash
# Web e Landing
npx next build

# API
npx tsc --noEmit && npm test
```

**Regras que valem para todo o ecossistema**
- Os `schema.prisma` do Web e da API precisam continuar em **paridade total**.
- **Nunca** use `--accept-data-loss` em alterações de banco.
- Regra de negócio fica na **API**. Os clientes só consomem.

> A licença MIT vale para o **código**. O nome e a marca **Hexavante**, o logo e o mascote são identidade da empresa.

## 🇺🇸 English

<details>
<summary><b>Read in English</b></summary>
<br/>

**Hexavante** is an education technology company. We design, build and operate our own platform, from database to deploy, with **one account, one dataset and one set of business rules** across web, API, public site, moderation panel, desktop and mobile.

- **Clients:** Web (Next.js 16), public landing (standalone Next.js), admin panel, Electron desktop and Expo mobile, all backed by one Fastify 5 API.
- **Data & security:** a single MySQL/MariaDB database with strict schema parity, Redis for cache/session/rate-limit, cookie sessions with 2FA and new-device verification.
- **Features:** video courses, community tutorials, objective + essay exams, XP/levels/coins/shop/season rankings, verifiable PDF certificates, live rooms, social feed, DMs, presence and full audited moderation.

**Open source:** the whole ecosystem is public under the **MIT license**. Issues and pull requests are welcome. Please report security vulnerabilities privately through the repository's **Security** tab.

**Repos:** [Web](https://github.com/Hexavante/Hexavante-Web) · [Api](https://github.com/Hexavante/Hexavante-Api) · [Landing](https://github.com/Hexavante/Hexavante-landing) · [Admin](https://github.com/Hexavante/Hexavante-admin) · [Desktop](https://github.com/Hexavante/Hexavante-Desktop) · [Mobile](https://github.com/Hexavante/Hexavante-Mobile)
