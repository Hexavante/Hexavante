## 🧭 Sobre

A **Hexavante** é uma empresa de tecnologia educacional. Construímos uma plataforma para estudantes de **tecnologia, ENEM e vestibulares**, reunindo conteúdo, prática, progresso e comunidade em um único ambiente.
